# 图论重要结论思维导图大纲

## 基本概念

### 握手定理
- 无向图握手定理
  - 度数之和等于边数两倍
- 有向图握手定理
  - 出度和等于入度和等于边数
- 奇度顶点性质
  - 奇度顶点个数为偶数
- 正则图性质
  - 阶数和度数不能同时为奇数
- 度数平均值
  - 最小度、平均度、最大度的不等式关系

### 度序列
- 图序列判定
  - 度数和为偶数的充要条件
- 简单图必要条件
  - 最大度不超过n-1
- Erdos-Gallai定理
  - 简单图序列的充要条件
  - 度数和为偶数
  - 每个k值的不等式条件
- 度数唯一性
  - 简单图顶点度数不能互不相同

### 图同构
- 必要条件
  - 顶点数相同
  - 边数相同
  - 度序列相同
  - 连通分支数相同
- 等价关系
  - 自反性、对称性、传递性

### 特殊图
- 完全图
  - 边数公式和正则性
- 自补图
  - 阶数模4的余数条件
- 二部图判定
  - 与奇圈的等价关系
- 完全二部图
  - 边数公式

### 连通性
- 连通图边数下界
  - 至少n-1条边
- 补图连通性
  - 原图不连通则补图连通
- 度数连通性
  - 基于最小度的连通条件
- 边数连通性
  - 基于边数的连通条件
- 连通等价条件
  - 任意划分都有跨越边

### 路与圈
- 路长度限制
  - 最长路不超过n-1
- 圈长度限制
  - 最长圈不超过n
- 最小度与圈长
  - 最小度与最短圈长度关系
- 偶圈存在性
  - 最小度大于等于3必含偶圈
- 圈长最大公约数
  - 最小度大于等于3时圈长gcd为1或2

### 距离与直径
- 距离性质
  - 对称性和三角不等式
- 直径连通性
  - 度数和条件下的连通性和直径
- 度数与直径
  - 最大度和直径的边数下界

## 树

### 树的等价定义
- 六个等价条件
  - 连通无圈
  - 任意两点唯一路径
  - 无圈且m=n-1
  - 连通且m=n-1
  - 连通且每条边都是桥
  - 无圈但加任意边得唯一圈
- 森林性质
  - k个连通分支有n-k条边

### 树的基本性质
- 树叶数量
  - 非平凡树至少有2片树叶
- 度数关系
  - 度数之和等于2(n-1)
- 星形图
  - 唯一分支点度数为n-1
- 路分解
  - 奇度顶点与路分解的关系
- 子树性质
  - 公共顶点导出子图仍是树

### 树的度序列
- 判定定理
  - 度数和等于2(n-1)的条件
- 构造方法
  - 归纳法构造过程

### 树的中心
- 中心定理
  - 中心由一个点或两个相邻点组成
- 应用
  - 中心点确定问题

### 生成树
- 存在条件
  - 与图连通性的等价关系
- 基本性质
  - 无圈子图与生成树关系
  - 弦和基本圈
  - 树枝和基本割集
- 凯莱公式
  - 完全图生成树数量
- 完全图减边
  - 减去一条边后的生成树数量

### 最小生成树
- Kruskal算法
  - 边权递增贪心策略
  - 时间复杂度和适用性
- Prim算法
  - 顶点扩展策略
  - 时间复杂度和适用性
- 破圈法
  - 删除圈中最大权边
- 算法正确性
  - 贪心选择性质

### 根树与编码
- 有序二元树
  - 与前缀码的对应关系
- Huffman树
  - 最优编码树的特性
- Huffman算法
  - 构造过程
