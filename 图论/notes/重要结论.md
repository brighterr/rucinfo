## 基本概念

### 握手定理

**记号**：$n$ = 顶点数，$m$ = 边数，$d(v)$ = 顶点$v$的度数

1. **无向图握手定理**：$\sum_{v \in V} d(v) = 2m$

2. **有向图握手定理**：$\sum_{v \in V} d^+(v) = \sum_{v \in V} d^-(v) = m$

3. **奇度顶点性质**：任何图中奇度顶点个数为偶数

4. **正则图性质**：$k$-正则图的阶数$n$和度数$k$不能同时为奇数

5. **度数平均值**：$\delta(G) \leq \frac{2m}{n} \leq \Delta(G)$

### 度序列

**记号**：$d_1 \geq d_2 \geq \cdots \geq d_n$ = 非增度序列

1. **图序列判定**：非负整数列$d$可图化 ⟺ $\sum d_i \equiv 0 \pmod 2$

2. **简单图必要条件**：简单图最大度$\Delta(G) \leq n-1$

3. **Erdos-Gallai定理**：序列$d_1 \geq \cdots \geq d_n$是简单图序列 ⟺ 
   - $\sum d_i$为偶数
   - $\forall k$：$\sum_{i=1}^k d_i \leq k(k-1) + \sum_{i=k+1}^n \min\{k,d_i\}$

4. **度数唯一性**：简单图的$n$个顶点度数不能互不相同

### 图同构

1. **必要条件**：若$G_1 \cong G_2$，则：
   - 顶点数相同：$|V_1| = |V_2|$
   - 边数相同：$|E_1| = |E_2|$
   - 度序列相同
   - 连通分支数相同

2. **等价关系**：图同构关系具有自反性、对称性、传递性

### 特殊图

1. **完全图**：$K_n$有$\binom{n}{2}$条边，是$(n-1)$-正则图

2. **自补图**：$n$阶自补图 ⟹ $n \equiv 0 \pmod 4$或$n \equiv 1 \pmod 4$

3. **二部图判定**：$G$是二部图 ⟺ $G$不含奇圈

4. **完全二部图**：$K_{r,s}$有$rs$条边

### 连通性

**记号**：$\omega(G)$ = 连通分支数

1. **连通图边数下界**：$n$阶连通图至少有$n-1$条边

2. **补图连通性**：若$G$不连通，则$\bar{G}$连通

3. **度数连通性**：若$\delta(G) \geq \lceil(n-1)/2\rceil$，则$G$连通

4. **边数连通性**：简单图若$m > \binom{n-1}{2}$，则$G$连通

5. **连通等价条件**：$G$连通 ⟺ 对$V$的任意划分$(V_1,V_2)$，存在跨越边

### 路与圈

1. **路长度限制**：$n$阶图中$u$到$v$的路长度$\leq n-1$

2. **圈长度限制**：$n$阶图中包含顶点$v$的圈长度$\leq n$

3. **最小度与圈长**：$\delta(G) \geq 2$ ⟹ $G$有长度$\geq \delta(G)+1$的圈

4. **偶圈存在性**：$\delta(G) \geq 3$ ⟹ $G$含偶圈

5. **圈长最大公约数**：$\delta(G) \geq 3$ ⟹ 圈长的$\gcd \in \{1,2\}$

### 距离与直径

**记号**：$d(u,v)$ = 距离，$diam(G)$ = 直径，$r(G)$ = 半径

1. **距离性质**：满足对称性和三角不等式

2. **直径连通性**：若不相邻顶点$u,v$满足$d(u)+d(v) \geq n-1$，则：
   - $G$连通
   - $diam(G) \leq 2$

3. **度数与直径**：若$\Delta(G) = n-2$且$diam(G) = 2$，则$m \geq 2n-4$

## 树

### 树的等价定义

**记号**：$T$ = 树，$n$ = 顶点数，$m$ = 边数

1. **六个等价条件**：对$n$阶$m$条边的简单无向图$G$，以下等价：
   - $G$是树（连通无圈）
   - $G$中任意两顶点间存在唯一路径
   - $G$中无圈且$m = n-1$
   - $G$连通且$m = n-1$
   - $G$连通且每条边都是桥
   - $G$无圈，但加任意一条新边得唯一的圈

2. **森林性质**：$k$个连通分支的森林有$n-k$条边

### 树的基本性质

1. **树叶数量**：$n$阶非平凡树至少有2片树叶

2. **度数关系**：树中$\sum d(v) = 2(n-1)$

3. **星形图**：唯一分支点度数为$n-1$的$n$阶树

4. **路分解**：有$2k$个奇度顶点的森林可分解为$k$条边不重的路

5. **子树性质**：两个子树的公共顶点导出子图仍是树

### 树的度序列

1. **判定定理**：序列$\{d_1, d_2, \ldots, d_n\}$满足$d_1 \geq d_2 \geq \cdots \geq d_n$且$\sum d_i = 2(n-1)$，则存在度序列为该序列的树

2. **构造方法**：归纳法构造，每次连接度数最大的顶点与新的叶子

### 树的中心

**记号**：$e(v)$ = 顶点$v$的离心率，$r(G)$ = 图的半径

1. **中心定理**：每棵树的中心由一个点或两个相邻点组成

2. **应用**：中心点确定问题（如医院选址）

### 生成树

**记号**：$\tau(G)$ = 图$G$的生成树数量

1. **存在条件**：无向图$G$有生成树 ⟺ $G$连通

2. **基本性质**：
   - 连通图的无圈子图是某个生成树的子图
   - 每条弦对应唯一的基本圈
   - 每条树枝对应唯一的基本割集

3. **凯莱公式**：$\tau(K_n) = n^{n-2}$

4. **完全图减边**：$\tau(K_n - e) = n^{n-3}(n-2)$

### 最小生成树

**记号**：$W(T)$ = 生成树$T$的权重

1. **Kruskal算法**：边权递增，避圈贪心选择
   - 时间复杂度：$O(m \log m)$
   - 适用：稀疏图

2. **Prim算法**：顶点扩展，选择最小权边
   - 时间复杂度：$O(n^2)$（邻接矩阵）
   - 适用：稠密图

3. **破圈法**：反复删除圈中最大权边直至得到树

4. **算法正确性**：贪心选择性质保证最优解

### 根树与编码

**记号**：$\sigma$ = 分支度，$l_i$ = 码长，$p_i$ = 概率

1. **有序二元树**：$\sigma = 2$的有序树，前缀码一一对应

2. **Huffman树**：最小化$\sum l_i p_i$的最优二元树

3. **Huffman算法**：
   - 合并两个最小权重叶子
   - 重复直到只剩一个根

4. **应用**：文件压缩、程序流程优化

## 平面图

## 欧拉公式

**记号**：$n$ = 顶点数，$m$ = 边数，$\phi$ = 面数，$k$ = 连通分支数

1. **欧拉公式**：连通平面图满足 $n - m + \phi = 2$

2. **广义欧拉公式**：$k$ 个连通分支的平面图满足 $n - m + \phi = k + 1$

3. **握手定理（面版本）**：$2m = \sum \deg(f)$

### 平面图的边数上界

1. **简单平面图**：$n \geq 3$ 时，$m \leq 3n - 6$
   - 等号成立 ⟺ 极大平面图（三角剖分）

2. **二分平面图**：$n \geq 3$ 时，$m \leq 2n - 4$

3. **一般化上界**：面度数 $\geq l$ 时，$m \leq \frac{l(n-2)}{l-2}$

4. **最小度限制**：简单平面图的最小度 $\delta \leq 5$

5. **平均度数**：简单平面图的平均度数 $< 6$

### 极大平面图

1. **三角剖分性质**：极大平面图的每个面都是三角形

2. **参数关系**：$n \geq 3$ 的极大平面图满足：
   - $m = 3n - 6$
   - $\phi = 2n - 4$

3. **连通性**：极大平面图必然连通且无割边（$n \geq 3$时）

### 平面图判定

1. **完全图**：$K_n$ 是平面图 ⟺ $n \leq 4$

2. **完全二分图**：$K_{a,b}$ 是平面图 ⟺ $a \leq 2$ 或 $b \leq 2$

3. **库拉托夫斯基定理**：$G$ 是平面图 ⟺ $G$ 不含 $K_5$ 或 $K_{3,3}$ 的同胚子图

4. **瓦格纳定理**：简单图 $G$ 是平面图 ⟺ $G$ 不含可收缩到 $K_5$ 或 $K_{3,3}$ 的子图

### 对偶图

1. **球面等价性**：图可球面嵌入 ⟺ 图可平面嵌入

2. **对偶图连通性**：平面图的对偶图必然连通

3. **参数对应**：
   - $G^*$ 的顶点数 = $G$ 的面数
   - $G^*$ 的边数 = $G$ 的边数  
   - $G$ 连通时，$G^*$ 的面数 = $G$ 的顶点数

4. **度数对应**：$\deg_{G^*}(v^*) = \deg_G(f)$

## 匹配 

### 基本定理

1. **Berge定理**：$M$ 是最大匹配 ⟺ $G$ 中不存在 $M$-可扩路

2. **Hall定理**：二分图 $G=(X,Y)$ 存在饱和 $X$ 的匹配 ⟺ $\forall S \subseteq X$，$|N(S)| \geq |S|$

3. **König定理**：二分图中，最大匹配边数 = 最小顶点覆盖数

4. **Tutte定理**：$G$ 有完美匹配 ⟺ $\forall S \subseteq V(G)$，$o(G-S) \leq |S|$

### 特殊图的匹配

1. **正则二分图**：$k$-正则二分图（$k>0$）存在完美匹配

2. **彼得森定理**：无割边的3-正则图存在完美匹配
   - 推广：$k$-正则连通图，顶点数偶数，边连通度 $\geq k-1$ ⟹ 存在完美匹配

3. **树的匹配**：
   - 树至多有一个完美匹配
   - 树有完美匹配 ⟺ $\forall v \in V(T)$，$o(T-v) = 1$

### 完美匹配计数

1. **完全图**：$K_{2n}$ 的完美匹配数 = $(2n-1)!!$

2. **完全二分图**：$K_{n,n}$ 的完美匹配数 = $n!$

## 着色理论 

### 边着色

**记号**：$\chi'(G)$ = 边色数，$\Delta$ = 最大度

1. **二分图**：$\chi'(G) = \Delta$（哥尼定理）

2. **简单图**：$\chi'(G) = \Delta$ 或 $\Delta + 1$（维津定理）
   - $\chi'(G) = \Delta$ → 第一类图
   - $\chi'(G) = \Delta + 1$ → 第二类图

3. **奇数阶图**：若 $n = 2k+1$ 且 $m > k\Delta$，则 $\chi'(G) = \Delta + 1$

4. **奇阶正则图**：$\chi'(G) = \Delta + 1$

5. **一般图**：$\chi'(G) \leq \Delta + \mu$（$\mu$ = 边的最大重数）

### 点着色

**记号**：$\chi(G)$ = 点色数

1. **基本不等式**：$\chi(G) \leq \Delta + 1$

2. **特殊图**：
   - 完全图：$\chi(K_n) = n$
   - 二分图：$\chi(G) = 2$（有边）
   - 轮图：$\chi(W_n) = 3$（$n$奇）或 $4$（$n$偶）

3. **平面图**：
   - 五色定理：$\chi(G) \leq 5$
   - 四色定理：$\chi(G) \leq 4$

4. **下界**：$\chi(G) \geq \frac{n^2}{n^2 - 2m}$

## 欧拉图

### 欧拉图与欧拉通路

**记号**：$\omega(G)$ = 连通分支数

1. **欧拉图判定**：连通图 $G$ 是欧拉图 ⟺ 所有顶点度数为偶数

2. **半欧拉图判定**：连通图 $G$ 有欧拉通路但无欧拉回路 ⟺ 恰有2个奇度顶点

3. **边集分解**：$G$ 是欧拉图 ⟺ $G$ 的边集可划分为若干个圈

4. **奇度顶点分解**：若 $G$ 有 $2k$ 个奇度顶点，则边集可分解为 $k$ 条边不重的迹

### 哈密尔顿图

**记号**：$\omega(G-S)$ = 删除 $S$ 后的连通分支数

1. **必要条件**：$H$-图 $G$ ⟹ 对任意 $S \subseteq V(G)$，$\omega(G-S) \leq |S|$
   - 推论：$H$-图无割点
   - 推论：奇数阶二分图非 $H$-图

2. **Ore定理**：对 $n \geq 3$ 的简单图，若任意不相邻顶点 $u,v$ 有 $d(u)+d(v) \geq n$，则 $G$ 是 $H$-图

3. **哈密尔顿路**：若任意不相邻顶点 $u,v$ 有 $d(u)+d(v) \geq n-1$，则 $G$ 有哈密尔顿路

4. **边数条件**：若 $m \geq \frac{n^2-3n+6}{2}$，则 $G$ 是 $H$-图

5. **Bondy定理**：若不相邻顶点 $u,v$ 满足 $d(u)+d(v) \geq n$，则 $G$ 是 $H$-图 ⟺ $G+uv$ 是 $H$-图
