# Rucinfo Hub

人大信息共享计划

## 关于本仓库

Rucinfo Hub 是由同学共同建设的人大信息共享计划，汇集学习笔记、技术博客与课程资料。

相关资料将持续整理与更新，欢迎同学提 PR 共同完善。

---

## 贡献

**欢迎贡献！**

Issue、PR、纠错、资料、选课/考试攻略，完全欢迎！

## 操作方法

提交 PR：Fork 本项目，然后在 GitHub 网页端点击 Upload File 上传文件，发起 PR 即可。留意一下项目的文件组织喔。

或者也可以直接附加在 Issue 中，由维护者进行添加。
