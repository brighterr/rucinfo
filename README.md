## 关于本仓库

本仓库由 RUC 信手相连项目组维护，汇集信息学院同学的学习笔记与技术博客。

信手相连的往届材料也将陆续更新，欢迎同学提 PR 共同完善。

## 操作方法

提交 PR：Fork 本项目，然后在 GitHub 网页端点击 Upload File 上传文件，发起 PR 即可。留意一下项目的文件组织喔。

或者也可以直接附加在 Issue 中，由维护者进行添加。
