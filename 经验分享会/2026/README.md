### 1. 联系导师与套磁

**问：** 保研找老师有哪些比较好的方法和渠道？套磁的时候，一般更着重考察基础知识还是科研项目？

**答：** 找老师主要有四种渠道：

- 直接发邮件。
- 社交媒体。
- 内推。
- QQ 群、微信群。

套磁时会考察对应方向的知识；如果简历上有科研项目，也会围绕科研项目提问。

### 2. 就业、读研与保研经历

**问：** 计算机本科就业情况如何？未来有哪些就业方向，薪资待遇怎样，市场会发生什么变化？读研有什么帮助？保研如何规划，怎样选择导师，又遇到过哪些困难？

**答：**

- **本科就业情况：** 看你的实习经历。
- **就业方向：** 互联网、泛体制。
- **薪资待遇：** 一人一薪。
- **就业市场变化：** 我的看法是，低级码农正在消亡。
- **读研的帮助：** 有更多时间做研究。
- **保研规划：** 最需要的是定位。
- **校内导师和业界联系多吗：** 多。
- **如何选择导师：** 根据气质。
- **保研过程中遇到的困难：** 论文写不完。
- **怎么克服：** “用命写完。”

### 12. 大二的学习科研安排与保研优势

**问：** 大二如何平衡学习和科研？现在对科研的要求越来越高，是不是没有好的科研成果，保研就没有优势？

**答：** 优先级仍然是 **绩点 > 科研**。

没有突出的科研成果，并不代表没有优势。高绩点加科研经历，也很有优势。

<a id="q13"></a>
### 13. 夏令营流程与大三发论文

**问：** 夏令营的整体流程是什么？大三发论文有什么经验？

**答：** 夏令营的整体流程是：**报名 → 入营 → 参营**。

发论文很看方向。我的体会是，2026 年之前需要投入大量时间；随着 AI 的发展，效率大幅提升。你需要很会、很会使用 AI。

<a id="q14"></a>
### 14. 夏令营考核与准备

**问：** 夏令营考核流程是怎样的，主要考哪些内容，如何准备？

**答：** 各个学校的考核流程不一样。英语基本必考，也会考察你填报方向的相关知识。

专业内容根据方向准备；通用的准备是英语。

<a id="q15"></a>
### 15. 数据库学习与入营后的考核

**问：** 数据库期中、期末有什么备考方法？保研入营后，尤其是清华、北大、人大，是不是就完全不看绩点，只看笔面试？考核范围和准备技巧有哪些？

**答：**

- **数据库备考：** 好好学习。
- **入营后是否还看绩点：** 面试会看成绩单，也可能追问为什么绩点低、为什么某门课没学好。
- **笔面试范围：** 根据具体夏令营决定。
- **通用准备：** 英语面试。

<a id="q17"></a>
### 17. 套磁时间与入营标准

**问：** 夏令营流程是什么？什么时候套磁？入营是不是只看绩点排名，会卡排名吗？

**答：**

- **流程：** 投递 → 入营 → 参营。
- **套磁时间：** 越早越好。
- **入营标准：** 多数营会卡绩点，但不只看绩点。我的判断是，如果没有顶级绩点，就要有顶级科研。

<a id="q18"></a>
### 18. 保研本校的准备

**问：** 如果只考虑保研本校，需要怎么做？

**答：** 绩点 + 学好专业课 + 学好英语。

信院考核会有专业课面试和英语面试。
